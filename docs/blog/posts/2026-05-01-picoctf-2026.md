## Web — Cookies (75pts)

### Challenge

> My friend made a website. Can you figure out what cookies they're using?

### Solution

Opened the site and checked cookies in browser devtools. Found:

```
name=0
```

Tried incrementing the value — each number returned a different page. At `name=18`:

```
That's a lot of snickerdoodles!
picoCTF{3v3ry1_l0v3s_c00k135_cc9110ba}
```

**Flag:** `picoCTF{3v3ry1_l0v3s_c00k135_cc9110ba}`

## Crypto — Caesar (25pts)

### Challenge

> Decrypt this message: `picoCTF{dspttjohuifsvcjdpo}`

### Solution

Classic Caesar cipher on the flag contents only (after `picoCTF{`). Tried ROT shifts — ROT-1 decoded it:

```bash
echo "dspttjohuifsvcjdpo" | tr 'a-z' 'z-abcdefghijklmnopqrstuvwxy'
# or just use CyberChef ROT13 variants
```

Shift of 1 backward: `d→c, s→r, p→o...` → `crossingtheRubicon`

**Flag:** `picoCTF{crossingtheRubicon}`

## Forensics — Wireshark doo dooo do doo (50pts)

### Challenge

> Can you find the flag in this packet capture?

### Solution

Opened the `.pcap` in Wireshark. Filtered for HTTP:

```
http
```

Followed the TCP stream on a suspicious GET request to `/flag`. The response contained a ROT13-encoded string:

```
cvpbPGS{p0mm4nd_1nj3ct10n_4_y0u_0b22a6b5}
```

Decoded with CyberChef → ROT13:

**Flag:** `picoCTF{c0mm4nd_1nj3ct10n_4_y0u_0b22a6b5}`

## Web — SQL Direct (200pts)

### Challenge

> Connect to this PostgreSQL server and find the flag.

### Solution

```bash
psql -h saturn.picoctf.net -p 61264 -U postgres pico
```

Password was `postgres` (default). Enumerated tables:

```sql
\dt
SELECT * FROM flags;
```

```
 id |         flag
----+-----------------------
  1 | picoCTF{L3arN_S0m3_5qL_t0d4Y}
```

**Flag:** `picoCTF{L3arN_S0m3_5qL_t0d4Y}`

## Key Takeaways

- Always check cookies — both their values and what happens when you modify them
- CyberChef is your best friend for quick cipher identification and decoding  
- Default credentials (`postgres:postgres`, `admin:admin`) are always worth trying
- For Wireshark — `http`, `dns`, and `tcp.stream` filters get you 90% of the way there
